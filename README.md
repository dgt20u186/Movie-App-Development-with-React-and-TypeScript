# Movie App

Приложение для просмотра информации о фильмах с использованием React, TypeScript, Material UI и API kinopoisk.dev.

## Функционал

- Бесконечная подгрузка списка фильмов (по 50 фильмов)
- Фильтрация по жанрам, рейтингу, году (с синхронизацией с URL)
- Детальная страница фильма
- Добавление в избранное с модальным подтверждением (сохранение в localStorage)
- Сравнение до двух фильмов (таблица сравнения)
- Маршрутизация (React Router)

## Запуск

1. Клонировать репозиторий
2. Создать файл `.env` на основе `.env.default` и добавить API-ключ
3. `npm install`
4. `npm run dev`

## Деплой

Приложение развёрнуто на Netlify: [ссылка](https://movie-app-demo.netlify.app)
